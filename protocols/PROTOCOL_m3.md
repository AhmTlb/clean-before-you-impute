# الورقة الثانية، المرحلة 3: تكرار مستقل (مثبّت قبل التشغيل)

## لماذا هذه المرحلة، بإفصاح كامل
- في المرحلة 2 (المجموعات 21 إلى 40) كانت الفرضيات السبع كلها في الاتجاه المتوقع، وست منها دالة قبل التصحيح، لكن **واحدة فقط** (H1 لـ KNN) تجاوزت تصحيح Holm.
- **قرار التوسعة اتُّخذ بعد رؤية هذه النتيجة.** لذلك:
  1. يُنشر حكم المرحلة 2 كما هو، دون تعديل، أياً كانت نتيجة هذه المرحلة.
  2. هذه المرحلة تُعرض **تكراراً مستقلاً** بحكمها الخاص.
  3. التحليل المُجمَّع يُعرض **تقديراً لحجم الأثر**، مع النص صراحة على أن قرار التوسعة جاء بعد رؤية نتيجة المرحلة 2.
- لا يُغيَّر في هذه المرحلة أي شيء: لا فرضية، ولا كمية، ولا ظرف، ولا نموذج، ولا معيار.

## البيانات
- مهام OpenML-CC18 **بعد** المجموعات الأربعين الأولى الصالحة، بنفس قواعد الصلاحية (200 متغير كحد أقصى، و100 صف كحد أدنى، و2000 صف كحد أقصى بعينة طبقية ثابتة).
- عددها غير معروف مسبقاً، والمتوقع نحو 20. **تُستخدم كلها أياً كان عددها**، ولا يُستبعد شيء بعد رؤية النتائج.
- 3 بذور، ونفس الكود (`missing_experiment_v2.py`) دون تعديل.

```
python missing_experiment_v2.py --source openml --max-datasets 72 --start 40 --seeds 3 --n-jobs 10 --out results_m3
python analyze_m2.py results_m3                 (حكم التكرار)
python analyze_m2.py results_m2 results_m3      (التحليل المُجمَّع)
python analyze_m1.py results_m3                 (الجداول الوصفية)
```

## الفرضيات (نفس المرحلة 2 حرفياً)
| الفرضية | الكمية (متوسط البذور ثم الظروف الستة S لكل مجموعة) | الاختبارات |
|---|---|---|
| **H1 الترتيب** | gain(dti) − gain(itd) مع التعويض التكراري > 0 | 4 |
| **H2 عبر المعوِّض** | gain(dti \| iter) − gain(dti \| native) > 0، لـ RF و HistGB | 2 |
| **H3 الانتشار** | log(RMSE ملوث / RMSE نظيف) للتعويض التكراري > 0 | 1 |

Wilcoxon أحادي الجانب عبر مجموعات البيانات، وتصحيح Holm على الاختبارات السبعة. الفرضية **مدعومة** إذا p_Holm < 0.05 والمتوسط في الاتجاه المتوقع. يُعرض مع كل اختبار فاصل ثقة 95% (bootstrap عبر المجموعات) لمتوسط الأثر.

## كيف ستُكتب النتيجة في الورقة (مقرر مسبقاً)
